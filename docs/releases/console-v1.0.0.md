# GreFlow Console 1.0.0

اولین نسخهٔ کنسول فارسی GreFlow برای ویندوز و لینوکس، کنار موتور و CLI سازگار v0.2.0.

## دریافت و اجرا

- ویندوز x64: `greflow-console-windows-amd64.zip` را کامل استخراج و `Start-GreFlow.ps1` را اجرا کنید.
- لینوکس: بستهٔ amd64 یا arm64 را استخراج کنید؛ `RUN.fa.md` و `install-console.sh` داخل بسته‌اند.
- پوشهٔ `helpers` را حذف نکنید. هر بسته ابزار سرور برای هر دو معماری را دارد.
- در اولین مراجعه به `http://127.0.0.1:8787` رمز پنل را تعیین کنید؛ کد راه‌اندازی و TOTP وجود ندارد.

## امکانات

مدیریت چند ایران و خارج با پسورد یا کلید SSH، نصب خودکار ابزار، شناسایی تانل‌های موجود،
کارت و جدول فارسی با IP خارج و اطلاعات Check-Host، وضعیت‌های مستقل، لاگ، گزارش مرحله‌ای،
مدیریت پورت و انتقال محدود TCP، زمان‌بندی روی ایران، حساب‌های دارای محدوده و بکاپ اختصاصی `.greflow`.
ابزارهای سرور شامل اطلاعات سیستم، لاگ SSH و ری‌استارت کل سرور با تأیید مجزا هستند.
رابط روشن و تاریک، Vazirmatn و پرچم‌های محلی دارد و برای موبایل و صفحه‌کلید بررسی می‌شود.

## سازگاری و محدودیت‌ها

- نصب ابزار، CLI یا تنظیمات و سرویس‌های تانل را بازنویسی یا ری‌استارت نمی‌کند.
- آماده‌سازی خودکار به root یا sudo از قبل مجاز نیاز دارد. فایل ابزار موجود ناسازگار خودکار جایگزین نمی‌شود.
- موتور GRE رمزنگاری یا احراز هویت ترافیک فراهم نمی‌کند؛ رمزنگاری برنامه‌ای مستقل لازم است.
- انتقال نسخهٔ اول فقط یک نگاشت TCP روی همان IP ورودی است؛ انتقال بین ایران‌ها، UDP و دامنهٔ پورت در این مسیر پشتیبانی نمی‌شوند.
- TCP موفق، پینگ، وضعیت سرویس و اطلاعات IP هیچ‌کدام تأیید اتصال واقعی کلاینت نیستند.
- اطلاعات مکان تقریبی و وابسته به Check-Host است؛ در قطع دسترسی نامشخص یا قدیمی نشان داده می‌شود.
- arm64 کراس‌کامپایل می‌شود؛ پوشش اجرای واقعی کرنل CI روی Linux amd64 است. آزمون تخریبی ری‌استارت سرور کاربر انجام نمی‌شود.
- نمودار تاریخی منابع، نصب خودکار نرم‌افزار مقصد، بازگردانی پیکربندی روی سرور راه دور و مهاجرت endpoint جزو این نسخه نیستند.

انتشار خودکار فقط بعد از عبور تست‌های ویندوز و لینوکس، مرورگر، race و تست کرنل GRE انجام می‌شود.
فایل‌های SHA256، فهرست وابستگی‌ها و مجوزها همراه بسته‌ها هستند. این نسخه امضای مستقل انتشار ندارد.
آموزش کامل در `USAGE.fa.md` و راهنمای خطاها در `TROUBLESHOOTING.fa.md` داخل هر بسته قرار دارد.
